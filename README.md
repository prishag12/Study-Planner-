# Study-Planner-

# Project Overview
A Java-based study planner designed to help students manage their study time more effectively. It creates personalized study schedules based on upcoming exams, confidence levels in different topics, and available study hours.

# Problem
Students often struggle to prioritize what to study, spending too much time reviewing familiar topics while neglecting areas where they need more practice. StudySync aims to make studying more organized and efficient.

# MVP Features 
- Allow users to enter subjects, topics, and exam dates.
- Let students rate their confidence in each topic from 1–5.
- Collect available study hours.
- Use a Java algorithm to prioritize topics based on confidence and exam urgency.
- Generate and display a personalized study schedule.
- Save study information and schedules to CSV files.

## Future Plans 
- Track completed study sessions and student progress.
- Integrate Google Calendar to organize study sessions.
- Explore AI-powered recommendations based on study performance.
- Add reminders for upcoming exams and study sessions.
